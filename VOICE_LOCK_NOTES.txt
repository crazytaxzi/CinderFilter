CinderFilter Voice Lock v1

1. Run START_CINDERFILTER.bat. The updated dependency install is larger because it adds PyTorch and SpeechBrain.
2. Select the physical microphone.
3. Press Enroll My Voice and speak normally for 12 seconds.
4. On first enrollment, allow the ECAPA speaker model to download.
5. Enable Voice Lock. Start with 24 dB and Balanced.
6. Choose Conservative if your own voice is reduced. Choose Aggressive if other voices still pass.

Voice Lock v1 identifies the dominant speaker. It does not yet fully separate two simultaneous overlapping voices.
